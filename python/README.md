# prediction-markets-nautilus

Schema-v2 to NautilusTrader adapter and deterministic replay spike for Polymarket BTC
five-minute prediction-market research. This package is an architecture-validation spike, not a
production trading implementation. It never places orders, connects a wallet, or calls
authenticated endpoints.

See `docs/nautilus-adapter-contract.md` for the intermediate contract and
`docs/nautilus-adoption-decision.md` for the adoption recommendation.
